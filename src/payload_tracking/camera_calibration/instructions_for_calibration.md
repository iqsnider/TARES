STEP 1: Generate a ChArUco Marker board by running `ChArUco_board.py`

STEP 2: Display the ChArUco Marker board on matte screen (e.g. a macbook screen or printed sheet)

STEP 3: Use calipers to measure the length of a black square (not the ArUco marker)

STEP 4: Input the measured length for the `SQUARE_LENGTH_m =` parameter at the top of `calibration.py`

STEP 5: Capture images of the board by following the on-screen instructions when running `capture_images_for_calibration.py`

STEP 6: Run `calibration.py`

STEP 7: Appreciate your brand new `calibration.json` file
